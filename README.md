# CareerPath_Backend_API

## Tech Stack

- **Backend API:** FastAPI (Python 3.11 - 3.13)
- **Database:** Neon Serverless PostgreSQL
- **AI Inference:** Groq Cloud SDK (`openai/gpt-oss-20b`, `whisper-large-v3`)
- **Document Ingestion:** PyMuPDF (`fitz`)
- **Data Validation:** Pydantic v2

---

## Quickstart for Team Members

Follow these steps to set up and run the backend testing environment locally:

### Clone the Repository
```bash
git clone <YOUR_GITHUB_REPO_URL>
cd gradpath-backend
```

### Create and activate virtual environment
```bash
# In Git Bash:
python -m venv venv
source venv/Scripts/activate
```

### Install dependencies
```bash
pip install -r requirements.txt
```
